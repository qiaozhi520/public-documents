# Official Website (Vite + Vue 3 + TypeScript + vue-router)

This is a minimal scaffold created for you.

Quick start:

1. Install dependencies:

```powershell
npm install
```

2. Run dev server:

```powershell
npm run dev
```

Internationalization
--------------------

This project includes basic i18n support via `vue-i18n`. Two locales are provided: English (`en`) and Simplified Chinese (`zh`). Use the language selector in the top-right of the nav to switch languages at runtime.

3. Build for production:

```powershell
npm run build
```

4. Preview build:

```powershell
npm run preview
```
